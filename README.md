# ห้องเรียนการสกัดกาแฟ

เว็บเครื่องมือโต้ตอบสำหรับเรียนหลักการสกัดกาแฟแบบดริป (Pour Over)

**เปิดใช้งาน:** https://kitiphong-kho.github.io/coffee-extraction-class/

## เจตจำนงของการใช้

เว็บนี้จัดทำขึ้น **เพื่อการเรียนการสอน** เพื่อให้ผู้เรียนเข้าใจหลักการสกัดกาแฟ (ทำไมรสชาติออกมาไม่พร้อมกัน ตัวแปรการชงมีผลอย่างไร) ผ่านการทดลองปรับค่า ทำแบบฝึกหัด และดูตัวอย่างสูตร ไม่ได้มุ่งเป็นเครื่องมือวัดหรือคาดการณ์ผลการชงจริง

## เนื้อหา

1. หลักการสกัดกาแฟ
2. Pour-Over Lab (ทดลองปรับตัวแปรดู EY และ TDS)
3. วิธีการสกัด Pour Over (สูตรพื้นฐานพร้อมตัวจับเวลา)
4. ฝึกแก้รสชาติ
5. แผนที่การชงกาแฟ (อ้างอิงเชิงลึก)
6. สูตรระดับโลก

## ข้อจำกัด

แบบจำลองและตัวเลขในหน้า Lab ถูกทำให้เรียบง่ายเพื่อดูทิศทางของผล ไม่ใช่ค่าวัดจริง ผลลัพธ์จริงขึ้นกับเมล็ด เครื่องบด น้ำ อุปกรณ์ และเทคนิคของแต่ละคน รายละเอียดแหล่งอ้างอิงอยู่ที่ส่วนท้ายของหน้าเว็บ

## ผู้จัดทำ

ศูนย์วิจัยพัฒนากาแฟคุณภาพ (Coffee Quality Research Center) มหาวิทยาลัยแม่ฟ้าหลวง

## การใช้งานทางเทคนิค

เป็นเว็บ static ไฟล์เดียว (`index.html`) ไม่มีระบบหลังบ้าน ไม่มีคุกกี้ และไม่มีระบบติดตามผู้ใช้
