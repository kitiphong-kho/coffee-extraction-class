# ห้องเรียนการสกัดกาแฟ — เว็บสำหรับเผยแพร่

ไฟล์ทั้งหมดเป็นเว็บแบบ static (ไม่ต้องมีเซิร์ฟเวอร์หลังบ้าน ไม่มีฐานข้อมูล ไม่มีคุกกี้ ไม่มีระบบติดตามผู้ใช้)

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเว็บทั้งหมด (HTML + CSS + JavaScript ในไฟล์เดียว) |
| `robots.txt` | อนุญาตให้ค้นหาเจอ |

## ก่อนเผยแพร่ (เช็กลิสต์)
- [ ] แก้ `<title>` และคำอธิบายใน `index.html` ถ้าต้องการ
- [ ] ถ้ามีโดเมนแล้ว ให้เพิ่ม `<link rel="canonical" href="https://โดเมนของคุณ/">` และ `og:url` ใน `<head>`
- [ ] ตัดสินใจเรื่องผู้จัดทำ/ลิขสิทธิ์/ติดต่อ (ตอนนี้ยังไม่มีชื่อผู้จัดทำในหน้า) แล้วเพิ่มในส่วนท้ายหน้า ("ที่มาและข้อจำกัด")
- [ ] ยืนยันว่าคุณมีสิทธิ์อ้างอิง "เอกสารประกอบการสอน Coffee Brewing" ตามที่ระบุในหน้า (สูตร 15 g / 225 g / 93 °C และตารางรสชาติ)

## วิธีเผยแพร่ (เลือกอย่างใดอย่างหนึ่ง)

**1. Netlify Drop (ง่ายสุด ไม่ต้องใช้ Git)** — เข้า app.netlify.com/drop แล้วลากโฟลเดอร์ `public-site` ไปวาง ได้ลิงก์ทันที

**2. Cloudflare Pages** — สร้างโปรเจกต์แบบ "Direct Upload" แล้วอัปโหลดโฟลเดอร์นี้

**3. GitHub Pages** — สร้าง repository ใหม่ อัปโหลดไฟล์ในโฟลเดอร์นี้ไว้ที่ราก (root) แล้วเปิด Settings → Pages → Deploy from branch (main, / root)

ทั้งสามแบบฟรีสำหรับเว็บ static และรองรับ HTTPS

## หมายเหตุทางเทคนิค
- ใช้ Google Fonts (Fraunces, Karla, JetBrains Mono) โหลดจาก fonts.googleapis.com ถ้าอยากไม่ให้เรียกบริการภายนอกเลย ให้ดาวน์โหลดฟอนต์มาเก็บในโฟลเดอร์เอง
- เก็บค่าที่ผู้ใช้ตั้งไว้ (แท็บล่าสุด ค่าใน Lab) ใน localStorage ของเบราว์เซอร์ผู้ใช้เท่านั้น ไม่ส่งออกไปที่ไหน
- ยังไม่มีรูปตัวอย่างสำหรับแชร์ (og:image) ถ้าต้องการให้ลิงก์แสดงภาพบน Facebook/LINE ให้เพิ่มรูปขนาด 1200×630 แล้วใส่ใน `<meta property="og:image">`
